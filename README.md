# mem-autorizacao

Página de retorno da autorização do piloto Prontidão Agêntica (MEM Inteligência Aplicada) no Mercado Livre.

O vendedor autoriza o app no Mercado Livre, volta para esta página e envia o código pelo WhatsApp. A página não envia dados sozinha, não usa análise de acesso e não é indexada.

Publicada em https://rodrigoevan.github.io/mem-autorizacao/
